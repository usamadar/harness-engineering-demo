# Prompt Recipes

These prompts are meant for live teaching. They show how a harness turns broad
intent into reliable agent work.

## Complete a Task

```text
Please complete tasks/01-add-sla-classification.md. Follow AGENTS.md and run
python3 scripts/check.py before finishing.
```

## Ask for a Harness Review

```text
Review this repo as a harness engineering demo. Tell me whether an agent has
enough context, execution support, feedback, governance, and memory to complete
small coding tasks reliably.
```

## Ask for a Focused Change

```text
Add a new routing rule for tickets about refunds. Keep business rules in
TicketRouter, add tests, and run the quality gate.
```
